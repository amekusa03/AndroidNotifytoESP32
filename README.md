# AndroidNotifytoESP32

Androidスマートフォンの通知をキャッチし、320x170ピクセルの画像データ（RGB565形式）に変換してESP32へ送信するアプリケーションです。

## 主な機能

- **通知のキャッチ**: システム通知を自動的に取得し、タイトル、本文、時刻を画像化します。
- **2つの送信モード**:
    - **TCP (Wi-Fi)**: ローカルネットワーク内のESP32へTCPソケット経由で高速に送信します。
    - **Bluetooth Classic (SPP)**: Wi-Fi環境がない場所でも、Bluetoothシリアル経由で送信可能です。
- **送信履歴の表示**: 直近20件の送信結果（成功/失敗）をメイン画面でリアルタイムに確認できます。
- **動的な設定変更**: ESP32のIPアドレスやBluetoothデバイス名をアプリ内でいつでも変更できます。

## セットアップ手順

### 1. 通知アクセス権限の許可
アプリを起動し、「通知アクセス設定を開く」ボタンから、本アプリ `AndroidNotifytoESP32` に対して通知へのアクセスを許可してください。

### 2. Bluetooth送信を利用する場合
- Androidのシステム設定から、送信先のESP32とあらかじめ**ペアリング**を済ませておいてください。
- アプリ起動時に「付近のデバイス」権限の許可を求められるので、許可してください。

## 使い方

1. **送信モードの選択**: 画面上のラジオボタンで「TCP (Wi-Fi)」または「Bluetooth」を選択します。
2. **接続情報の設定**:
    - **TCPの場合**: ESP32の固定IPアドレスを入力します。
    - **Bluetoothの場合**: ペアリング済みのESP32のデバイス名を入力します。
3. **転送の開始**: 通知が届くと、設定したモードで自動的に転送が開始されます。履歴エリアでステータスを確認してください。

## 技術仕様

- **画像サイズ**: 320 x 170 ピクセル
- **データ形式**: RGB565 (Big Endian)
- **Bluetoothプロファイル**: SPP (Serial Port Profile) - UUID: `00001101-0000-1000-8000-00805f9b34fb`
